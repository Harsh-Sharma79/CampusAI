# Visual asset research

- Image search: `calm modern university library student studying laptop wide workspace photography` (2026-09-30). Search results were stock-library listings (Shutterstock, Adobe Stock, Dreamstime, iStock) and appeared watermarked or license-gated; none are used in CampusAI.
- Original hero photograph: generated specifically for CampusAI as a cinematic 21:9 student-in-library study-space background and bundled at `public/hero-study-space.webp` so both managed Preview and local Vite runs use the same self-contained asset.
- The CampusAI product icon and favicon are original inline SVG/CSS treatments; app iconography uses Lucide React.
